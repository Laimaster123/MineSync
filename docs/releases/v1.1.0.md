**What's new in 1.1.0**

- **MineSync suggests where you played last.** After each sync it remembers the state of the world, so next time it picks the right computer by itself — and warns you if the world was changed on both computers.
- **Faster and more reliable transfer.** Data that compresses well is sent compressed; if Wi-Fi drops for a moment, the transfer continues where it stopped; every file is checked with SHA-256. If the world changes on the other computer during the transfer (e.g. it was opened in the game), nothing is replaced.
- **Update check.** On startup MineSync checks for a new version and offers to download it (can be turned off in Settings).
- **All error messages are translated** to the interface language.
- Fixes: the app no longer crashes on a damaged settings file or when started twice with the same data; temporary files are kept next to the worlds (fast even when an instance is on another disk); the network server is protected from broken and hanging connections.

**Downloads**
- **macOS (Apple Silicon):** `MineSync-1.1.0-macOS.zip` — unzip and replace `MineSync.app` in Applications.
- **Windows (64-bit):** `MineSync-1.1.0-Windows.zip` — unzip and replace the old `MineSync` folder (keep the whole folder together).

Pairing, instances, history and backups are kept. Update **both computers**: compression, resuming and the direction hint work fully when both run 1.1.0 (1.0.0 on the other computer still syncs).

**Что нового в 1.1.0**

- **MineSync подсказывает, где играли последним.** После синхронизации программа запоминает, каким стал мир, и в следующий раз сама отмечает нужный компьютер — а если мир изменился на обоих, предупреждает.
- **Передача быстрее и надёжнее.** То, что хорошо сжимается, идёт по сети сжатым; если Wi-Fi на мгновение пропал, передача продолжится с того же места; каждый файл проверяется SHA-256. Если мир на другом компьютере изменился прямо во время передачи (например, его открыли в игре), ничего не заменяется.
- **Проверка обновлений.** При запуске программа проверяет, нет ли новой версии, и предлагает её скачать (можно выключить в настройках).
- **Все сообщения об ошибках** — на языке интерфейса.
- Исправления: программа не падает из-за повреждённого файла настроек и при повторном запуске; временные файлы лежат рядом с мирами (быстро, даже если сборка на другом диске); сервер защищён от испорченных и зависших соединений.

**Скачать**
- **macOS (Apple Silicon):** распакуйте `MineSync-1.1.0-macOS.zip` и замените `MineSync.app` в «Программах».
- **Windows (64-bit):** распакуйте `MineSync-1.1.0-Windows.zip` и замените старую папку `MineSync` (папку не разделяйте).

Пара, сборки, история и бэкапы сохранятся. Обновите **оба компьютера**: сжатие, докачка и подсказка направления полностью работают, когда на обоих стоит 1.1.0 (с 1.0.0 на втором компьютере синхронизация тоже работает).
